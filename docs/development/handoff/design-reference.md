# Дизайн VetPetCare: источник и перенос

Владелец поручил использовать дизайн-систему [gregoryprod/vetpetcare/landing](https://github.com/gregoryprod/vetpetcare/tree/main/landing). Это согласованный источник будущего UI CRM, а не уже выполненный перенос.

Для воспроизводимости зафиксирован commit **`efb80662982b05db9e5eec80b8e1b05c6a9a3ab8`**:

- [landing/DESIGN.md](https://github.com/gregoryprod/vetpetcare/blob/efb80662982b05db9e5eec80b8e1b05c6a9a3ab8/landing/DESIGN.md), Git blob `e1871c5b6bb844905d5bcbc1facf04fb9a19228e`.
- [landing/styles.css](https://github.com/gregoryprod/vetpetcare/blob/efb80662982b05db9e5eec80b8e1b05c6a9a3ab8/landing/styles.css), Git blob `f3b8b2990953eda0514c5ee94c4f1cf82c473a7b`.

[design-tokens.yaml](design-tokens.yaml) — извлечённый YAML frontmatter DESIGN.md: палитра, типографика, размеры, компоненты. [design-tokens.css](design-tokens.css) — точный блок `:root` styles.css. Это reference-файлы; они пока не подключены в приложение. Снимок не содержит тексты сайта, реальные контакты, фотографии, PRODUCT.md или бизнес-данные соседнего репозитория. Для обновления сначала сравни новую версию источника и сохрани причину изменения.

Основные правила источника: льняной фон `#efece3`, бумажные карточки `#f8f6f0`, оранжевое действие `#c1521e`, hover `#a2410f`, основной текст `#161616`, вторичный `#595959`; Onest, табличные цифры, плоские поверхности, мягкие скругления и пилюли. `#757575` используется для декора, а не мелкого текста. Акцент обозначает действие/выбор. Рукописные пометки — точечный фирменный приём, не обязательное украшение каждого экрана.

Предлагаемый перенос в CRM: сначала токены, локальные шрифты с лицензией и базовые кнопки/поля/статусы; затем вход, навигация, таблицы и карточки; затем календарь, чат и виджет. Подбери рабочую плотность и семантику статусов для CRM, сохранив фирменную основу. Размеры лендингового hero и анимации не являются готовым проектом календаря или таблицы. Семантические цвета успешных/предупреждающих состояний и новые паттерны потребуют отдельного решения/проверки контраста.

DoD задачи переноса: указать источник токенов, не сломать приём/правки лидов, проверить клавиатуру/фокус/ошибки/пустые состояния, desktop и 390px, `prefers-reduced-motion`, читаемость плотных данных. Шрифты/ассеты загрузить из разрешённого источника отдельно; ссылки на отсутствующие файлы не подключать. Сейчас `src/app/globals.css` использует прежнюю нейтрально-зелёную палитру: её замена будет отдельным проверяемым PR.
