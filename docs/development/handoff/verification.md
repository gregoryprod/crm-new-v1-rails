Бинарники, `.env`, база Beads и node_modules с рабочего Mac-каталога не копировались.

Независимое ревью выявило одну ошибку первоначальной инструкции: `npm test` не загружает `.env`. Она воспроизведена в чистом клоне до подключения БД; команда с `node --env-file` проверена на отдельной тестовой БД и добавлена в инструкции. Итоговое ревью и CI относятся к финальному head PR #14 и публикуются в [issue #13](https://github.com/artemiyvladimirov-cmyk/vpc-crm/issues/13) / [PR #14](https://github.com/artemiyvladimirov-cmyk/vpc-crm/pull/14), чтобы этот снимок не выдавал старый SHA за текущий.

Ограничения: Docker на этом Mac отсутствует; clean-clone runtime проверен на собственном локальном PostgreSQL 14, это дополнительный синтетический fixture. Поддерживаемый сценарий compose использует PostgreSQL 17; реальные PG17-проверки приложения выполняются GitHub Actions на Node 22/24. Самостоятельная проверка compose на компьютере Артёма остаётся частью его bootstrap. Новый UI не изменялся; браузерная проверка desktop/390 относится к базе PR #12. Production, реальные данные, внешний тестовый Telegram и платежи в эту проверку не входят. Локальный стенд пользователя на :3103 сохранён.

Сырые логи, временная БД и синтетические credentials в Git не публикуются. Временный проверочный сервер после smoke остановлен; эта проверка не является развёрнутым стендом Артёма.
