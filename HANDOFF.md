## Получить полный комплект

На 11.10.2026 `main` содержит каркас CRM; приём лидов находится в открытом [PR #12](https://github.com/artemiyvladimirov-cmyk/vpc-crm/pull/12). [PR передачи #14](https://github.com/artemiyvladimirov-cmyk/vpc-crm/pull/14) в ветке `chore/issue-13-agent-handoff` построен поверх PR #12 и включает его код. На новом компьютере:

```sh
gh auth status
gh repo clone artemiyvladimirov-cmyk/vpc-crm
cd vpc-crm
git fetch origin
git switch --track origin/chore/issue-13-agent-handoff
git status --short
```

Это команда для нового клона без одноимённой локальной ветки. Если ветка уже слита/удалена, обнови `main`, проверь, что `HANDOFF.md` и принятый PR #12 там есть. В существующем рабочем каталоге сначала сохрани незавершённые изменения; не выполняй reset/clean. Не считай открытые PR слитыми. После принятого merge #12 PR передачи нужно перевести на `main`, повторно проверить его diff/CI и принять отдельно.

## Готовое первое поручение агенту

Скопируй этот текст в Codex, Claude Code или другой агент, запущенный **в каталоге клона**:

> Восстанови проект CRM VetPetCare из этого репозитория. Прочитай HANDOFF.md, AGENTS.md, README.md, docs/development/handoff/README.md, state.json, team.json и план v1-delivery.md. Затем прочитай GitHub context issue #7, issue #3/#4/#13 с последними комментариями, открытые PR и CI. Проверь ветку, SHA и незавершённые изменения. Установи закреплённый Beads через scripts/install-beads.py; если базы нет — bootstrap из refs/dolt/data, если есть — dolt pull. Используй только scripts/beads.py, сверяй external_ref, зависимости и последние checkpoints. Пока ты восстанавливаешь контекст, не делай claim и не пиши в Beads; согласуй единственного оркестратора с Артёмом. Подними локальную CRM на синтетических данных по инструкции, проверь health, вход и доступ к списку/карточке лида. Сообщи, какие PR приняты, что работает в твоём клоне, какие доступы отсутствуют и следующую разрешённую задачу. Цель следующей разработки уже согласована: полная CRM v1 по ТЗ, этапами, с дизайном VetPetCare из указанного источника; оркестратор GPT-6.1-Sol xhigh, исполнители GPT-6-Luna, независимое read-only ревью. Это описание команды, а не установленный runner. До исполнения декомпозируй сценарии в GitHub Issues/Beads по общим правилам. Merge, production, реальные выгрузки, платежи и сообщения клиентам требуют прямой команды владельца. Если источник или доступ недоступен, обозначь пробел, не выдумывай данные и не создавай второй backlog.

Агент может прочитать всё из клона и доступного GitHub. Учётные записи GitHub/провайдеров, локальные секреты и разрешение стать единственным писателем Beads задаёт Артём у себя. Передачу приватного кода новому внешнему провайдеру отдельно разрешает владелец; прежнее разрешение Claude для issue #3 не является общим разрешением на будущие задачи.
